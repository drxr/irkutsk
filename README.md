# СППР психиатрической службы Иркутской области

Главный экран ведёт от изменения показателей к доступным группам пациентов,
месту проживания, нозологии и исходной ячейке. Клик по году меняет год разбора,
клик по столбцу открывает следующий уровень. Есть возврат, сброс и выбор группы
с клавиатуры. Цвет территории и цвета категорий фиксированы.

Обновлённый локальный Streamlit-прототип по расширенному брифу заказчика и новым данным населения. Отдельный пакет для техлида и обсуждения с заказчиком. Студентам можно передать пакет парсера; готовый интерфейс СППР в студенческий комплект не добавлен.

## Запуск

Клонировать репозиторий и перейти в его папку. Python 3.10 или новее:

```bash
git clone https://github.com/drxr/irkutsk.git
cd irkutsk
python -m venv .venv
source .venv/bin/activate
```

В Windows PowerShell вместо последней команды использовать `.venv\Scripts\Activate.ps1`.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

После запуска открыть адрес, который покажет Streamlit, обычно `http://localhost:8501`.
Население уже включено в комплект и загружается автоматически: 2 056 областных
знаменателей за 2013–2024 годы, муниципальное население и таблицы сверки.
Ручная загрузка после запуска не требуется. В этом снимке репозитория нет
формы 36 за 2022 год; для неё можно подключить полный архив.

Новый формат: `data/medical/form_10_all_years_long.csv`,
`data/medical/form_36_all_years_long.csv` и
`data/population/population_denominators_2013_2024.csv` (или `.csv.gz`).
Поддерживается прежнее расположение двух медицинских CSV непосредственно в `data/`.
Без населения приложение работает с абсолютными числами, а ставки остаются пропусками.
Без медицинских CSV приложение показывает инструкцию загрузки внизу меню.
Большие таблицы населения сохранены в gzip без изменения CSV. Приложение
читает их напрямую; обновлённый несжатый CSV имеет приоритет перед `.csv.gz`.
Источники и контрольные суммы — в `data/population/README.md` и `bundle_manifest.json`.

Данные можно хранить вне репозитория:

```bash
export IRKUTSK_DATA_DIR="/путь/к/комплекту/data"
python -m streamlit run app.py
```

В PowerShell: `$env:IRKUTSK_DATA_DIR="C:\путь\к\data"`.
Для Docker можно смонтировать папку: `-v "/путь/к/data:/app/data:ro"`.
Новые медицинские файлы в рамках изменения интерфейса не добавляются в GitHub.

Для Docker:

```bash
docker build -t psychiatry-dss .
docker run --rm -p 8501:8501 psychiatry-dss
```

Основа приложения — версия 5 архива `psychiatry_dss_streamlit_irkutsk.zip`
от 13 октября 2026 года. Состав полного архива отличается от текущего снимка
данных в GitHub. Прежняя проверка архива описана в `docs/validation.md`,
проверка нового обзора — в `docs/narrative_update.md`, подключение населения —
в `docs/population_connection.md`. Старые снимки экранов
сохранены как история; исходный бриф остаётся в архиве.

Также поддерживается объединённая медицинская выгрузка
`psychiatry_all_long.csv` или `psychiatry_all_long.csv.gz`.

Для 2022–2024 годов включить переключатель «Использовать расчётное среднегодовое население», если нужен предварительный показатель на 100 тыс. Числа помечаются как расчётные. Если метод ещё не согласован, оставить переключатель выключенным: абсолютные значения доступны.

## Что изменилось

| Раздел | Что можно сделать |
|---|---|
| Обзор | Крупные KPI → фактический вывод → год на графике → возраст/пол → город/село → нозология → источник и вопрос на рабочую встречу |
| Заболеваемость и структура | Выбрать общую/первичную, нозологию, пол, возраст, город/село; сравнить абсолютные значения и ставки |
| Наблюдение и помощь | Изучить диспансерный/консультативный контингент, движение, инвалидность, поступления, нозологии и доли по форме 10 |
| Нагрузка и ресурсы | Посмотреть посещения, занятые должности, дневной стационар, прокси нагрузки и арифметический сценарий |
| Динамика и события | Описательно сравнить периоды без причинных выводов |
| Прогноз | Проверить возможность прогноза, сравнить линейный тренд с последним значением по прошлым годам |
| Население и покрытия | Проверить типы знаменателей, пробелы, версии муниципальных рядов и методы расчёта |
| Сравнения и запросы | Посмотреть муниципальное население и реестр выполнения брифа |
| Аномалии и качество | Изучить сигналы, причины исключения и реестр проверки PDF |
| Данные и методика | Найти формулу и исходную ячейку, выгрузить таблицу и рассчитанные ряды |

Загрузка медицинских CSV и населения находится внизу бокового меню. Сохранены логотип Волны и подпись команды.

## Как устроен разбор по клику

1. Выбрать общую или первичную заболеваемость и год. Точку года можно выбрать на графике.
2. Начать один из маршрутов: возраст, пол или место проживания.
3. Нажать столбец группы — откроется следующий доступный разрез. При выборе возраста пол сбрасывается к обоим полам; при выборе пола возраст сбрасывается к всем возрастам.
4. Дойти до основной группы заболеваний и открыть источник. Во всех деталях, текстовых выводах и экспорте используется один выбранный срез.
5. Вернуться на предыдущий уровень или сбросить путь. Для клавиатуры и телефона есть список и кнопка открытия группы.

Группы 55+ в форме нет. Нельзя получить «мужчины 55+» или муниципальный рейтинг
из имеющихся областных итогов. Муниципальный и федеральный медицинские разрезы
остаются недоступными до получения сопоставимых данных.

Легенда: бирюзовый — ряд Иркутской области; фиксированные цвета — категории;
фиолетовый пунктир — модельный прогноз. Красный статус означает замечания к данным,
зелёный — отсутствие замечаний в доступных проверках, янтарный — сигнал для разбора,
серый — недостаточно данных. Рост и снижение заболеваемости сами по себе не окрашиваются
как «хорошо» или «плохо». Пройденные проверки не означают ручной сверки всех PDF.

## Правила доверия

По умолчанию непроверенный OCR и расчётное среднегодовое население не включаются в основные показатели. Эти настройки независимы: разрешение расчётного населения не подтверждает качество OCR.

Пропуски не заменяются нулями, не заполняются предыдущими годами и не соединяются годовым процентом изменения. Возрастные числители не делятся на общее население. Мужчины и городские жители — разности сопоставимых итогов. Совместного разреза пола и возраста в форме 10 нет.

Для годовых зарегистрированных и впервые выявленных используется среднегодовое население, для контингентов на конец года — численность на 1 января следующего года. Реальная дата и метод находятся в экспорте. Правила прототипа нужно подтвердить с заказчиком по определениям показателей.

Подтверждённое значение 80 546 за 2017 год сохранено вместе с исходным OCR и основанием исправления. Форма 36 за 2022 есть в полном архиве; в исходнике есть пометка о непредназначенности файла для сдачи в МИАЦ, статус окончательности нужно уточнить. В текущем снимке GitHub этот файл отсутствует.

## Что пока ограничено данными

- Среднегодовой возрастной численности за 2022–2024 нет. Переключатель расчётного населения не создаёт отсутствующие разрезы.
- Муниципальные медицинские числители и геометрия границ не переданы. Поэтому карты заболеваемости и муниципальные рейтинги не построены.
- Сопоставимые показатели России и федеральных округов отсутствуют.
- Для обеспеченности врачами, укомплектованности и круглосуточными койками нужен полноценный ряд формы 30. Занятые должности не переименованы в физических лиц врачей.
- Поступления в стационар не равны уникальным госпитализированным пациентам. Охват уникальных пациентов ими не подменяется.
- PDF-таблицы за 2017–2019 нужно дополнить и проверить. Существующий реестр не доказывает полной обработки всех страниц.
- Опубликованные возрастные средние и среднее двух январских срезов различаются; версии муниципального и областного рядов также требуют сверки.

В строгом режиме непрерывный ряд заболеваемости — пять лет, поэтому прогноз заблокирован. При исследовательском режиме модель запускается только если после фильтра качества остаётся минимум восемь непрерывных лет. Однолетняя проверка не считается проверкой двухлетней точности; доверительный интервал не придуман.

## Как обновлять

Получить `output` из отдельного нового парсера и выполнить:

```bash
python update_data.py "/путь/к/парсеру/output"
```

Затем перезапустить Streamlit. Альтернатива для временной проверки — загрузить CSV через боковое меню. Загрузка действует только в текущем сеансе. Медицинские CSV должны относиться к Иркутской области; население другой территории не применяется.

Выгрузки можно использовать для самостоятельного дашборда Tableau из брифа. Этот пакет — Python/Streamlit-прототип, не файл Tableau.

## Проверка

```bash
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```

Проверены расчёты, сохранение источников, пропуски, сдвиги граф, фильтры и запуск всех десяти экранов через Streamlit AppTest. Прежняя проверка полного архива — `docs/validation.md`; проверка маршрутов и нового экрана — `docs/narrative_update.md`.

Цели заказчика «ускорить обработку на 70%» и «анализ на 80%» сохранены в реестре. Это ожидаемый эффект; его подтверждают замером времени до и после внедрения.
