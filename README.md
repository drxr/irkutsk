# Волна данных — психиатрическая служба Иркутской области

Рабочее Streamlit-приложение для управленческого разбора годовых форм 10 и 36.
Код, два CSV, методика, исследования и тесты находятся в этом комплекте.
Данные относятся ко всей Иркутской области. Город Иркутск отдельно не выделен.

## Запуск

Нужен Python 3.12 или 3.13. Распакуй архив и открой терминал в папке проекта.

```bash
python -m venv .venv
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Затем:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Открыть http://localhost:8501. Загрузка данных не требует API или ключей.
Приложение работает локально. CSV в data/ используются по умолчанию.
Загруженные через боковую панель CSV полностью заменяют пример; исходные файлы не перезаписываются.

Если запускаешь из существующей Anaconda, используй `python -m streamlit run app.py`,
чтобы приложение и установка зависимостей работали в одном окружении.
При ошибке `TypeError: 'str' object cannot be interpreted as an integer` обнови
`app.py` из этого комплекта. Способ задания ширины таблиц и графиков теперь
выбирается по API установленного Streamlit; старым версиям передается
`use_container_width=True`, новым — `width="stretch"`.

Для Docker:

```bash
docker build -t psychiatry-dss .
docker run --rm -p 8501:8501 psychiatry-dss
```

## Как устроен экран

1. **Обзор:** большой главный вывод, четыре карточки, динамика и приоритетные сигналы.
2. **Динамика и события:** COVID, 24.02.2022, сравнение фактических доступных лет.
3. **Структура пациентов:** возраст, сельские жители, три непересекающиеся группы и уточнение диагнозов.
4. **Нагрузка и ресурсы:** занятые должности, посещения, стационар, дневная помощь, занятость, арифметический сценарий.
5. **Аномалии и качество:** причины подсветки, полнота отчетов, балансы и сомнительные ячейки.
6. **Данные и методика:** первичные таблицы, формулы, исследования, источники и выгрузки.

Сигнал ведет к вопросу для проверки и следующему действию. На обзоре есть редактируемый план рабочей встречи и его экспорт в CSV. План хранится только в текущем сеансе до скачивания.

## Что есть в комплекте

- app.py — интерфейс Streamlit и графики Plotly.
- analytics.py — функциональные расчеты без классов; пропуски, качество и адреса ячеек явные.
- assets/volna-logo.svg — векторный логотип Волны; включён в комплект и работает без сети.
- data/ — присланные пользователем выгрузки с журналом подтверждённых исправлений в docs/data_corrections.json.
- docs/research_and_design.md — исследовательская записка и принятые решения.
- docs/sources.json — ссылки и роль каждого источника.
- docs/validation.md — результаты проверки.
- .streamlit/config.toml — палитра и конфигурация.
- tests/ — смысловые проверки расчетов и основных экранов.
- requirements.txt — проверенные версии зависимостей.

В боковом меню сначала идут разделы и фильтры. Загрузка CSV перенесена
в нижний раскрывающийся блок «Загрузка данных». Ниже размещена подпись
«С уважением, команда Волны». При обновлении приложения копируй также
папку assets с логотипом, либо замени папку проекта целиком из архива.

## Интерпретация

Сводные данные — 23 отчета, 2013–2024, 14 795 непустых ячеек. Формы 36 за 2022 год нет.
Последний год в этих данных — 2024, а не текущий год работы приложения.

По умолчанию используем цифровые и отдельно сверенные ячейки. digital означает происхождение из цифрового документа, а не аудит достоверности отчетности. OCR 2017–2019 можно включить для исследования; сомнительные значения требуют сверки.

7 октября 2026 года пользователь подтвердил 80 546 зарегистрированных пациентов
за 2017 год (форма 10, таблица 2000, строка 1, графа 4). Это значение включено
и в обычный режим качества. Исходный результат OCR сохранён; остальные
ячейки отчёта за 2017 год этим подтверждением не сверены.

X, пустые поля и отсутствующие отчеты не становятся нулями. Линии не соединяются через пропуски. Годовое изменение сравнивает только соседние календарные годы.

С 2023 года в ряде таблиц формы 36 сдвинулись графы. В коротких таблицах 2120 и 2150 номера граф Excel 2020/2023 отличаются от Word. Словарь учитывает эти различия. Итоговые диагностические группы формы 10 определяются по названию: в 2013 номеров строк меньше. Подстроки «из них» не суммируются с итогами.

Сведения о попытках и завершенных попытках относятся к двум учетным группам таблицы 2150. Они не являются региональной суицидальной смертностью. Две группы показаны отдельно; индивидуальный риск не вычисляется.

Сравнение периодов после 24.02.2022 описательное: это разница наблюдаемых средних. Нет контрольного региона, месячных данных и идентификатора участников СВО; причинного вывода приложение не делает. Первое документированное окно самоизоляции выделено в описании; окно 2020–2021 на графике — пандемический аналитический контекст, не юридический срок карантина.

Приложение поддерживает добавление среднегодового населения для учетных показателей на 100 тыс. Шаблон можно скачать на экране динамики. Население не выдумано и не подставлено из несопоставимого источника.

## Проверки

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты проверяют числовые адреса разных редакций, короткие таблицы Excel/Word, пропуски, нулевые знаменатели, исключение OCR, безопасные сравнения и работу экранов.

## Развитие

Для следующего этапа нужны данные об ожидании и муниципалитетах, штатных вакансиях и среднегодовых FTE, связанных эпизодах и исходах, PROMs/PREMs, причинах смерти и среднегодовом населении. Их наличие даст возможность измерять результат помощи, а не только учетный объем.
